# 💖 Instituto Amor e Cuidar — Website

Site institucional desenvolvido para o **Instituto Amor e Cuidar**, com foco em apresentação dos serviços, contato e divulgação das atividades.

---

## 🚀 Tecnologias utilizadas

* ⚛️ React
* ⚡ Vite
* 📘 TypeScript
* 🎨 Tailwind CSS
* 🔗 React Router
* 🎯 Lucide Icons

---

## 📱 Funcionalidades

* Layout moderno e responsivo (mobile + desktop)
* Navegação entre páginas
* Seções institucionais:

  * Home
  * Quem Somos
  * Serviços
  * Valores
  * Galeria
  * Contato
* Galeria com slider de imagens
* Botão de WhatsApp para contato direto
* Menu mobile com sidebar
* Integração com Instagram
